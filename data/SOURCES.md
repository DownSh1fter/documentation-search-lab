# Corpus sources / Источники корпуса

## English

`corpus.jsonl` is generated by `scripts/build_corpus.py` from the selected pages below. The script pins Python 3.15.0, downloads each page, extracts its sections, and splits long sections into passages of up to 220 words with a 35-word overlap. Each passage contains a source URL with its section anchor.

## Русский

Файл `corpus.jsonl` создаётся скриптом `scripts/build_corpus.py` из выбранных страниц ниже. Скрипт фиксирует версию Python 3.15.0, загружает страницы, извлекает разделы и делит длинные разделы на фрагменты до 220 слов с перекрытием 35 слов. У каждого фрагмента сохранена ссылка на исходную страницу и якорь раздела.
