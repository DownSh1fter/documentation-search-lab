# Documentation Search Lab

[English version](README.md).

Учебный проект по поиску информации в технической документации. Цель — сравнить поиск по словам и семантический поиск, измерить качество выдачи, разобрать ошибки и научиться возвращать ответы с подтверждающими ссылками на источники.

## Зачем этот проект

Это личный учебный проект для практики ML-инженерии: подготовки корпуса, создания воспроизводимой выборки для оценки, расчёта метрик поиска, анализа ошибок, разработки API и небольшой демонстрации. Будем записывать результаты вместе с версией данных и ограничениями оценки.

## Текущий статус

Первая запускаемая версия — лексический поиск TF-IDF по небольшому учебному корпусу, написанному вручную. Он помогает разобраться в устройстве пайплайна, но не является бенчмарком. Перед оценкой качества поиска заменим его настоящими документами.

## Быстрый запуск

```bash
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell
.venv\Scripts\Activate.ps1
python -m pip install -e .
python -m doc_search.cli "How do I read a text file?"
```

## Этапы проекта

1. Определить задачу, источники корпуса и формат оценки.
2. Измерить лексический бейзлайн с помощью Recall@k и MRR.
3. Добавить семантический поиск и сравнить его на тех же вопросах.
4. Разобрать ошибки и при необходимости попробовать гибридный поиск или переранжирование.
5. Добавить генерацию ответов с цитатами и отказом отвечать без подтверждения.
6. Запустить систему через FastAPI и Docker; описать воспроизводимый запуск и результаты.

## Принципы оценки

- Разделять вопросы для разработки и итоговую отложенную выборку.
- Сравнивать изменения поиска на одном и том же зафиксированном наборе вопросов.
- Публиковать метрики поиска и примеры ошибок; не приводить единственную цифру accuracy без контекста.
- Записывать версию корпуса, название модели, настройки и случайное зерно вместе с результатами.

## Структура репозитория

```text
data/                 исходные документы и вопросы для оценки
src/doc_search/       загрузка данных, поиск, оценка и API
reports/              сохранённые метрики и разбор ошибок
```

## Данные и лицензия

Сейчас в `data/corpus.jsonl` находятся оригинальные учебные фрагменты, пересказывающие понятия из документации Python. Это не бенчмарк. URL источников и сведения о лицензии собраны в `data/SOURCES.md`.

Код распространяется по лицензии MIT. Не добавляйте в репозиторий личные или закрытые данные.
